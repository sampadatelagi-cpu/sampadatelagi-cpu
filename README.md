### Hi, I'm Sampada Telagi 👋

CS + Cell & Molecular Biology at Barnard College, Columbia University — building software at the intersection of the two, with the goal of making healthcare and research more reachable for people without deep technical training or lab access.

I'm drawn to projects where the code has to answer to something real — a diagnosis, a research bottleneck, a person who got left out of the room where the tool was designed.

### 🔬 Projects

- **[Bioinformatics Tool Advisor](https://github.com/sampadatelagi-cpu/Bioinformatics-tool-advisor)** — an LLM-reasoning API that recommends the right molecular docking method (HDOCK vs. HADDOCK) for a researcher's stated goal, built to close a real expertise gap I ran into doing docking research this summer
- **[Symptom Logger](https://github.com/sampadatelagi-cpu/Symptom-logger)** — a structured symptom-tracking tool built to help patients bring accurate, dated information into doctor visits instead of foggy recall
- **[DNA Sequencing Translator](https://github.com/sampadatelagi-cpu/DNA-Translator)** — a codon translator using a 3D NumPy lookup for O(1) codon resolution instead of the usual dictionary/string parsing
